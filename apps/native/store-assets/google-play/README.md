# Google Play 스토어 등록 그래픽 에셋

`adb`로 실제 기기(SM-S926N, 1440×3120) 화면을 캡처하고 `sharp`로 가공해 만든,
**Play Console 등록정보 > 그래픽** 업로드용 에셋이다. 모두 규격·용량·알파(투명도)
조건을 충족한다(알파 없음 = 24-bit PNG).

## 파일 / 규격 / 업로드 위치

| 파일 | 규격(실측) | 용량 | Play Console 업로드 항목 |
|---|---|---|---|
| `icon/icon-512.png` | 512×512 PNG, 알파 없음 | 8KB (≤1MB) | **앱 아이콘** |
| `feature/feature-1024x500.png` | 1024×500 PNG, 알파 없음 | 48KB (≤15MB) | **그래픽 이미지**(feature graphic) |
| `screenshots/01~05-*.png` | 1080×1920 PNG(9:16), 알파 없음 | 각 ≤330KB (≤8MB) | **휴대전화 스크린샷**(2~8장) |

- 아이콘: 원본 `assets/images/icon.png`(투명 모서리)를 브랜드색 `#256EF4`로 flatten →
  Play 아이콘은 투명도 불가하므로 알파 제거. 풀블리드 정사각형(스토어가 자동 마스킹).
- 휴대전화 스크린샷: 9:16 정확(1080×1920). 캡처 원본 상단 상태바(USB 디버그 아이콘 등)와
  하단 제스처바를 잘라낸 뒤 라운드코너 폰목업 + 한글 캡션을 얹었다.

## 스크린샷 구성 (순서 = 스토어 노출 순서)

| # | 화면 | 캡션 |
|---|---|---|
| 01 | 홈 | 내 시장을 한눈에 — 지수·관심종목·뉴스를 한 화면에 |
| 02 | 종목 상세 | 실시간 차트로 종목 분석 — 기간별 시세와 관련 뉴스까지 |
| 03 | 시그널 | AI 매매 시그널 알림 — 매수·매도·관망 타이밍을 한 곳에 |
| 04 | 뉴스 | AI가 요약하는 시장 뉴스 — 긴 기사도 핵심만 빠르게 |
| 05 | 마이 | 맞춤 알림과 관심 종목 관리 — 가격·시그널·뉴스 알림 설정 |

## 원본 캡처

`screenshots/raw/` = 가공 전 기기 원본(1440×3120). 다른 화면으로 교체하거나
캡션을 바꿀 때 재가공 소스로 사용한다. (`raw/`는 업로드 대상 아님)

## 재생성 방법

1. 기기 USB 연결 + `adb devices` 확인
2. 앱 화면을 `adb exec-out screencap -p > raw/<name>.png` 로 캡처
3. `sharp`(브랜드색·캡션·라운드코너 합성)로 가공 — 생성 스크립트는 1회용으로
   작업 디렉터리에서 실행했다. 동일 절차: 캔버스 그라데이션 `#2E74F5→#143C9E`,
   캡션 폰트 `Apple SD Gothic Neo`, 스크린샷 라운드 40px·세로 1380px 중앙 배치.

> 주의: 캡처에 노출된 데이터는 테스트 계정(test@test.com)·모의 시세다. 공개 전
> 실데이터/실계정 노출 여부를 확인할 것.
