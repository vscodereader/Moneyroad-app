# RFC 0010 — 머니게이트 회사 소개 웹사이트 전면 재설계 (company-website-redesign)

- 상태: **Draft**
- 작성일: 2026-07-30
- 대상 앱: `apps/company`
- 대상 도메인: `https://moneygate.ai.kr/`
- 디자인 기준: `https://qt-advisor.com/`
- 콘텐츠 보강 참고:
  - `http://kiwoomcompany2019.co.kr/`
  - `https://chesleyasset.com/`
- 범위: 정보구조, 콘텐츠, 비주얼 시스템, 인터랙션, 컴포넌트 구조, 반응형·접근성·성능, 배포 전 실데이터 검증 기준
- 제외: 이 RFC에서는 **설계서만 작성**한다. `apps/company` 구현 파일, 패키지, 배포 설정은 변경하지 않는다.

---

## 0. 이 RFC가 확정하는 요구사항

1. 머니게이트 사이트의 현재 회사·사업·서비스·준법·문의 정보는 삭제하지 않고 새 구조에 맞게 재배치한다.
2. 색상, 여백, 카드, 타이포그래피, 헤더, 히어로, 스크롤 등장 효과, 인터랙티브 물결은 QT Advisor의 시각 언어를 기준으로 다시 설계한다.
3. Kiwoom Company와 Chesley Asset은 **콘텐츠 항목의 누락을 찾는 용도**로만 참고한다. 두 사이트의 디자인, 문장, 사진, 로고, 수치 또는 영업 표현을 복제하지 않는다.
4. 회사 개요, 대표 인사말, 사업·서비스, 정보 제공 절차, 운영 원칙, 투자자 보호, 공지·공시, FAQ, 오시는 길·문의가 모두 존재해야 한다.
5. 대표자·사업자번호·신고번호·주소·전화·이메일 등 미확정 정보는 섹션을 생략하지 않고 명시적인 더미 데이터로 렌더링할 수 있게 한다.
6. 더미 데이터는 미리보기에서만 허용한다. 프로덕션 배포 전 자동 점검으로 실제 값 교체를 강제한다.
7. 금융감독원·국세청·SGI서울보증·대한변호사협회 로고 영역은 설계에 포함하되, 실제 관계와 로고 사용 권한이 확인된 항목만 공개한다.
8. 기관 영역은 **설명 카드·설명 문장·상태 badge 없이 로고만 가로 한 줄로 배치**한다. 섹션 제목도 화면에 표시하지 않는다. 단순 신고·조회 관계를 제휴나 보증처럼 보이게 하지 않기 위한 검증 규칙은 코드와 내부 체크리스트에만 둔다.
9. 대표 서비스 머니로드의 뉴스 문구는 `AI 요약`이 아닌 **`머니로드 요약`**으로 통일한다.
10. 오래된 `0~100점 시그널` 중심 홍보는 제거하고 현재 구현 기준인 관심종목, 시세·차트, 매수·매도·관망 시그널, 머니로드 요약, 가격 알림, 종목 토론을 소개한다.
11. 유사투자자문업의 범위를 벗어나는 1:1 맞춤 자문, 투자일임, 고객 자산 운용, 수익률 보장, 목표수익률, 원금 보장 표현은 사용하지 않는다.
12. 새 애니메이션 패키지를 추가하지 않는다. Canvas, `requestAnimationFrame`, `IntersectionObserver`, CSS transition으로 구현한다.

## 3. 사실성·법적 표시 원칙

### 3-1. 프로덕션에서 사실 확인이 필요한 필드

```ts
type CompanyProfile = {
  name: string;
  nameEn: string;
  ceo: string;
  bizNumber: string;
  corporateNumber?: string;
  telecomSalesNumber?: string;
  reportNumber: string;
  reportAuthority: string;
  foundedAt?: string;
  address: string;
  email: string;
  phone: string;
  fax?: string;
  businessHours?: string;
  mapUrl?: string;
};
```

- 미리보기 기본값은 `홍길동 (예시)`, `000-00-00000 (예시)`처럼 더미임이 화면에서도 분명해야 한다.
- 프로덕션 빌드에서는 `(예시)`, `TODO`, `000-00-00000`, 빈 문자열을 검사해 실패시킨다.
- 설립일, 임직원 수, 자본금, 특허, 수상, 고객 수, 다운로드 수는 근거가 없으므로 기본 데이터에 넣지 않는다.

### 3-2. 기관 마크 노출 규칙

화면에는 설명을 붙이지 않고 다음처럼 로고만 표시한다.

```text
[금융감독원]   [국세청]   [SGI서울보증]   [대한변호사협회]
```

- 데스크톱에서는 네 로고를 한 줄 중앙 정렬한다.
- 모바일에서는 가로 스크롤 한 줄로 유지한다. 2×2 카드로 바꾸지 않는다.
- 카드 배경, 설명, 상태 badge, `자세히 보기` 문구를 넣지 않는다.
- 각 로고의 시각적 높이는 28–36px로 통일하고 원본 종횡비를 유지한다.
- 기본은 흰색 또는 회색조 로고이며 hover에서만 원색으로 전환할 수 있다.
- 링크를 연결하는 경우 화면에는 글자를 추가하지 않고 로고 자체가 링크가 된다.
- 접근성을 위한 `alt`와 새 창 안내는 스크린리더 전용 텍스트로만 제공한다.

| 기관 | 공개 가능한 조건 | 조건 미충족 시 |
|---|---|---|
| 금융감독원/FINE | 머니게이트 신고 조회 URL·신고번호 확인 | 로고 숨김 |
| 국세청/홈택스 | 실제 사업자등록번호 확인 | 로고 숨김 |
| SGI서울보증 | 실제 보증보험 계약·증권 및 명칭 사용 허가 | 로고 숨김 |
| 대한변호사협회 | 실제 고문변호사·법률 자문 관계와 표시 동의 | 로고 숨김 |

기관 로고가 표시되더라도 다음 문구는 금지한다.

- `머니게이트를 보증합니다`
- `공식 제휴기관`
- `정부 인증 기업`
- `대한변협 인증`

단순 조회 링크를 보여주는 경우에는 `외부 기관 사이트에서 회사 정보를 확인할 수 있습니다`라고만 설명한다.

### 3-3. 투자 관련 금지 표현

- 안정적인 수익 보장
- 손실 없는 투자
- 목표 수익률 달성
- 종목 추천을 그대로 따르면 수익
- 1:1 맞춤형 종목 상담
- 고객 대신 매매·운용
- 특정 종목의 매수·매도 강요

서비스 화면 예시는 항상 `특정 종목의 매매를 권유하지 않는 예시 화면`이라는 설명을 함께 둔다.

## 4. 디자인 시스템

### 4-1. 방향

키워드는 `정교함`, `데이터`, `신뢰`, `절제된 미래감`이다. QT Advisor의 다크 금융 테크 분위기를 따르되 머니게이트 로고와 머니로드의 파란색을 브랜드 중심으로 쓴다.

### 4-2. 색상 토큰

```css
:root {
  --company-bg: #0f1114;
  --company-bg-elevated: #191f28;
  --company-surface: #222a36;
  --company-surface-strong: #364152;
  --company-primary: #3b82f6;
  --company-primary-strong: #2563eb;
  --company-primary-soft: rgba(59, 130, 246, 0.14);
  --company-text: #f9fafb;
  --company-text-muted: #b1b8be;
  --company-text-subtle: #8a949e;
  --company-border: rgba(255, 255, 255, 0.1);
  --company-border-strong: rgba(255, 255, 255, 0.18);
  --company-success: #34d399;
  --company-warning: #fbbf24;
  --company-danger: #fb7185;
}
```

- 페이지 기본 배경은 `#0F1114`.
- 섹션을 `#0F1114`와 `#191F28`로 교차한다.
- 흰색 섹션은 사용하지 않는다.
- 본문 대비는 WCAG AA 이상을 확보한다.
- 매수·매도 색만으로 뜻을 전달하지 않고 반드시 텍스트 라벨을 함께 쓴다.

### 4-3. 타이포그래피

- 현재 Geist를 유지해 패키지와 폰트 다운로드를 늘리지 않는다.
- 한글 fallback은 시스템 산세리프를 사용한다.
- 히어로: 데스크톱 `clamp(3.5rem, 7vw, 6.5rem)`, 모바일 `clamp(2.5rem, 12vw, 4rem)`.
- 섹션 제목: `clamp(2rem, 4vw, 3.75rem)`.
- 본문: 16–18px, line-height 1.7.
- 작은 고지: 최소 13px, line-height 1.65.
- 강조는 굵기·색상으로 처리하며 불필요한 전부 대문자 영문은 피한다.

### 4-4. 형태와 공간

- 최대 콘텐츠 폭: `1200px`.
- 페이지 좌우 여백: 모바일 20px, 태블릿 32px, 데스크톱 40px.
- 섹션 상하 여백: 모바일 88px, 데스크톱 144px.
- 대형 카드 radius: 28–32px.
- 일반 카드 radius: 20–24px.
- 버튼은 pill 형태, 최소 높이 48px.
- 테두리는 흰색 10% 이하, hover에서 18%로 올린다.
- 그림자는 검정 그림자보다 낮은 투명도의 파란 glow를 쓴다.

### 4-5. 아이콘·이미지

- 기존 `LogoMark`, `icon.svg`, `lucide-react`를 재사용한다.
- 경쟁사 스크린샷과 이미지를 제품 자산으로 사용하지 않는다.
- 머니로드 화면은 `apps/web/public/screens`를 바로 참조하지 않고 승인된 동일 원본을 `apps/company/public/moneyroad/`에 복사해 앱 간 빌드 결합을 만들지 않는다.
- 실제 화면이 준비되지 않으면 CSS로 구성한 제품 카드 목업을 사용한다.
- 기관 로고는 공식 배포 파일을 출처 기록과 함께 `public/verification/`에 저장한다. 웹에서 임의 캡처한 저해상도 이미지는 사용하지 않는다.

## 5. 공통 인터랙션

### 5-1. 히어로 물결

`HeroWaveCanvas` 클라이언트 컴포넌트를 만든다.

- 전체 히어로 뒤를 덮는 하나의 Canvas
- 2–3개의 부드러운 사인 곡선 위에 점 또는 짧은 선분을 배치
- 시간에 따라 위상과 진폭이 천천히 변해 물결이 계속 흐름
- 포인터와 각 점의 거리가 가까울수록 밝기, 크기, 곡선 변형량 증가
- 포인터 중심에는 파란색·흰색 radial glow
- 포인터가 Canvas를 떠나면 300–500ms 동안 원래 상태로 감쇠
- Canvas는 장식이므로 `aria-hidden="true"`, 포인터 이벤트는 위치 추적 외 클릭을 가로채지 않음
- `devicePixelRatio`는 최대 2로 제한
- resize 시 Canvas 크기와 점 간격 재계산
- 화면 밖이거나 탭이 숨겨지면 애니메이션 일시 정지

권장 계산:

```text
baseY = centerY + sin(x * frequency + time * speed) * amplitude
distance = hypot(pointerX - x, pointerY - baseY)
influence = max(0, 1 - distance / pointerRadius)
y = baseY + pointerDirectionY * influence * 28
alpha = baseAlpha + influence * 0.75
```

정확한 QT Advisor 코드를 복제하지 않고 동일한 사용자 경험을 독립 구현한다.

### 5-2. 스크롤 reveal

`ScrollReveal`은 `IntersectionObserver`를 사용한다.

- 초기: `opacity: 0`, `transform: translateY(40px)`
- 등장: `opacity: 1`, `translateY(0)`
- duration: 700ms
- easing: `cubic-bezier(0.22, 1, 0.36, 1)`
- 카드 묶음 stagger: 80ms
- threshold: 0.16
- 한 번 나타난 요소는 다시 숨기지 않는다.
- JavaScript 실패 시 콘텐츠가 숨은 채 남지 않도록 기본 HTML은 표시 상태이고, hydration 뒤에만 초기 클래스를 적용한다.

### 5-3. 모션 감소

`prefers-reduced-motion: reduce`에서는:

- Canvas를 정적인 한 프레임으로 표시
- reveal transform과 stagger 제거
- 자동으로 움직이는 장식 제거
- hover 색상·focus outline은 유지

### 5-4. 헤더

- 상단 고정, 처음에는 투명한 검정
- 24px 이상 스크롤하면 `rgba(15,17,20,.82)` + blur + 아래 테두리
- 데스크톱 중앙 내비, 우측 `머니로드 보기`와 `문의하기`
- 모바일은 로고, 문의 CTA, 햄버거
- 모바일 메뉴는 포커스 트랩과 ESC 닫기 지원
- 현재 라우트와 현재 섹션에 `aria-current` 적용

## 8. 상세 페이지 설계

### 8-1. `/company`

#### 회사개요

- 회사명, 영문명, 대표자, 설립일, 사업자번호, 신고번호, 주소, 대표 연락처

- 가짜 인물 사진 생성 금지
- 실제 대표 승인 후 문구와 서명 교체

#### 운영 원칙

- 투자자 보호
- 불특정 다수에 동일 정보 제공
- 개별 투자자문·일임 미제공

- 오류 발견 시 정정

#### 조직과 사람

- 대표이사, 서비스·제품, 데이터·리서치, 운영·고객지원, 준법·정보보호의 5개 역할 그룹

- 대표자와 공개 승인된 주요 인력만 얼굴·이름·약력을 표시한다.
- 사진이 없으면 가짜 인물 사진을 만들지 않고 이름 이니셜 그래픽을 사용한다.
- 주요 인력 카드에는 `이름`, `직책`, `담당`, `공개 가능한 주요 경력`을 둔다.
- 더미 인물은 반드시 이름 뒤에 `(예시)`를 표시한다.

- 문의 유형: 서비스, 제휴, 보도·미디어, 기타
- 백엔드가 없으므로 제출되는 것처럼 보이는 가짜 폼은 만들지 않는다.
- 1차 구현은 `이메일 문의`, `전화 문의`, `지도 보기` CTA로 구성한다.
- 문의 API를 별도로 승인받으면 폼과 개인정보 동의·보관 기간을 추가한다.

## 12. 접근성·성능·SEO

- Lighthouse 목표: Performance 85+, Accessibility 95+, Best Practices 95+, SEO 95+

### 12-3. SEO

- canonical은 `https://moneygate.ai.kr`
- `robots.ts`, `sitemap.ts`
- Organization JSON-LD는 실데이터가 모두 확정된 뒤 활성화
- 대표 OG 이미지는 별도 승인 자산 사용

## 14. 검증 시나리오

### 14-1. 기능

- 모든 상단 메뉴와 Footer 링크가 실제 라우트로 이동

### 14-2. 비주얼

- QT Advisor처럼 짙은 2단계 배경, 흰 제목, 파란 포인트가 일관됨

- hover가 없는 터치 환경에서도 정보 손실 없음
- 360, 768, 1024, 1440px 캡처 비교

### 14-3. 법적·콘텐츠

- `AI 요약`이 남아 있지 않고 `머니로드 요약`으로 표시
- `72/100`, `0~100점` 중심 홍보가 없음
- 1:1 자문·일임·수익 보장 표현이 없음
- 실제 관계가 확인되지 않은 SGI·대한변협 로고가 공개되지 않음
- FINE 링크와 신고번호가 실제 회사 정보와 일치
- 모든 더미 값이 프로덕션에서 제거됨

- FINE의 머니게이트 직접 조회 URL

# 부록 A. 화면에 바로 사용할 회사·브랜드 원고

이 부록의 문장은 경쟁사 문구를 복사하지 않고 머니게이트의 현재 사업 범위에 맞춰 새로 작성한 더미 초안이다. 구현자는 `이런 내용이 필요하다`는 제목만 렌더링하지 말고 아래 원고를 실제 콘텐츠 데이터에 넣는다. 대표 인사말과 회사 실정보는 최종 공개 전에 회사 승인을 받는다.

## A-1. 홈 Hero

### Eyebrow

`DATA · CONTEXT · RESPONSIBILITY`

### 제목

```text
시장의 수많은 정보를
판단할 수 있는 흐름으로
```

두 번째 줄 또는 `판단할 수 있는 흐름으로`를 파란색으로 강조한다.

### 본문

> 머니게이트는 공개된 시장 데이터와 뉴스, 종목별 신호를 이해하기 쉬운 맥락으로 정리합니다. 누구나 같은 정보에 접근하고 스스로 판단할 수 있도록, 근거와 한계를 함께 전하는 투자정보 서비스를 만듭니다.

### CTA

- Primary: `머니로드 알아보기`
- Secondary: `회사 소개 보기`

### Hero 원칙 지표

수치가 아닌 검증 가능한 원칙만 사용한다.

| 강조값 | 설명 |
|---|---|
| 불특정 다수 | 특정 개인이 아닌 모든 이용자에게 동일한 정보 제공 |
| 데이터 기반 | 시장 데이터·뉴스·이벤트를 일관된 기준으로 정리 |
| 판단 지원 | 매매를 대신하지 않고 이용자의 독립적 결정을 도움 |
| 위험 고지 | 정보의 한계와 원금 손실 가능성을 함께 안내 |

## A-2. 회사 요약

### 제목

`정보가 많아질수록, 기준은 더 선명해야 합니다.`

### 본문 1

> 투자자는 매일 시세, 공시, 뉴스, 기술적 지표와 수많은 의견을 마주합니다. 정보는 빠르게 늘어나지만 서로 다른 출처와 시간대에 흩어져 있어, 필요한 내용을 찾고 연결하는 데 많은 시간이 듭니다.

### 본문 2

> 머니게이트는 흩어진 정보를 종목과 주제, 시간의 흐름에 맞춰 정리합니다. 하나의 숫자나 문장으로 결론을 단정하기보다 어떤 변화가 있었고 무엇을 함께 살펴봐야 하는지 보여줍니다.

### 본문 3

> 우리는 이용자의 자산을 대신 운용하지 않습니다. 수익을 보장하거나 특정 종목의 매매를 강요하지도 않습니다. 투자자가 정보를 더 분명하게 이해하고 자신의 기준으로 판단하도록 돕는 것이 머니게이트의 역할입니다.

## A-3. 미션·비전·약속

### Mission

제목: `정보의 비대칭을 줄입니다.`

> 시장 참여자 누구나 필요한 정보에 접근하고, 근거와 위험을 함께 확인하며, 스스로 판단할 수 있는 환경을 만듭니다.

### Vision

제목: `투자 판단의 신뢰할 수 있는 출발점`

> 관심 종목을 확인하는 순간부터 뉴스, 시그널, 가격 변화와 시장 의견을 살펴보는 과정까지 하나의 흐름으로 연결하는 정보 플랫폼을 지향합니다.

### Promise

제목: `정답보다 근거를, 확신보다 투명성을`

> 결과를 미리 단정하지 않고 정보가 만들어진 배경과 한계를 함께 설명합니다. 잘못된 정보는 숨기지 않고 확인·정정하며 변경 내용을 알립니다.

## A-4. 대표 인사말 더미 원고

제목: `투자자가 스스로 판단할 수 있는 정보를 만들겠습니다.`

제목: `긴 뉴스는 핵심부터 읽으세요.`

### 기능 4 — 가격 알림

제목: `다시 확인할 가격을 미리 정하세요.`

> 사용자가 설정한 가격에 종목이 도달하면 다시 확인할 시점을 알려줍니다. 알림은 매수나 매도를 자동 실행하지 않으며 기기·네트워크·시장 데이터 상황에 따라 지연될 수 있습니다.

제목: `다른 투자자의 관점도 참고하세요.`

> 종목별 토론방에서 시장 참여자의 다양한 의견과 대화 흐름을 확인할 수 있습니다. 토론 내용은 머니게이트의 공식 의견이나 매매 권유가 아니며 작성자 개인의 의견입니다.

| 영향 판단 | 이용자에게 미치는 범위와 긴급성 판단 |
| 수정 | 잘못된 데이터·요약·연결 정보 수정 또는 비노출 |
| 안내 | 중요한 변경은 공지 또는 해당 콘텐츠의 정정 표시로 안내 |
| 재발 방지 | 원인과 동일 유형의 다른 항목을 점검 |

화면용 문구:

> 잘못된 정보를 발견하면 문의 채널로 알려주세요. 확인이 필요한 항목은 원문과 데이터 기준시각을 검토하고, 오류가 확인되면 수정 내용과 시점을 가능한 범위에서 안내합니다.

## C-3. 데이터 지연·장애 안내

> 시장 데이터와 알림은 거래소, 정보 제공처, 네트워크와 기기 상태의 영향을 받을 수 있습니다. 지연 또는 누락이 발생할 수 있으므로 실제 매매 전에는 이용 중인 증권사와 공식 공시를 함께 확인해야 합니다.

장애 상태는 다음 단계로 표시한다.

- 정상
- 일부 데이터 지연
- 일부 기능 제한
- 점검 중
- 복구 완료

실시간 상태 페이지는 별도 시스템이 없으면 만들지 않고 공지사항으로 안내한다.

# 부록 E. 더미 FAQ 24개

FAQ는 다른 회사 사이트의 질문 범주를 참고하되 머니게이트의 유사투자자문업·정보 서비스 범위에 맞게 새로 작성한다.

## E-1. 회사·신고

### Q1. 머니게이트는 어떤 회사인가요?

머니게이트는 공개된 시장 데이터와 뉴스, 종목 관련 정보를 정리해 불특정 다수의 이용자에게 제공하는 투자정보 회사입니다. 대표 서비스로 관심종목, 뉴스, 시그널, 가격 알림과 종목 토론을 제공하는 머니로드를 운영합니다.

### Q2. 유사투자자문업자는 무엇인가요?

유사투자자문업자는 불특정 다수를 대상으로 간행물, 전자매체 등의 방식으로 투자 관련 정보를 제공하는 사업자입니다. 정식 투자자문업·투자일임업과 업무 범위가 다르며, 머니게이트는 개별 이용자에게 1:1 맞춤 자문을 제공하거나 이용자의 자산을 대신 운용하지 않습니다.

### Q3. 머니게이트의 신고 정보는 어디에서 확인할 수 있나요?

회사 정보 페이지에 표시된 신고번호를 확인한 뒤 금융감독원 금융소비자 정보포털 FINE의 유사투자자문업 신고 현황에서 조회할 수 있습니다. 프로덕션에서는 머니게이트를 바로 확인할 수 있는 공식 조회 링크를 연결합니다.

### Q4. 머니게이트는 금융투자회사나 증권사인가요?

아닙니다. 머니게이트는 증권사, 자산운용사, 투자일임사가 아니며 고객의 주문을 체결하거나 자산을 보관·운용하지 않습니다. 실제 매매는 이용자가 선택한 증권사를 통해 직접 결정하고 실행해야 합니다.

### Q5. 회사 대표자와 사업자 정보는 어디에서 볼 수 있나요?

회사소개와 Footer에서 대표자, 사업자등록번호, 신고번호, 주소, 대표 연락처를 확인할 수 있습니다. 사이트에 표시된 정보와 공식 조회 결과가 다르면 대표 문의처로 알려주세요.

## E-2. 투자정보와 책임

### Q6. 특정 종목을 1:1로 추천받을 수 있나요?

제공하지 않습니다. 머니게이트는 불특정 다수에게 동일한 투자 참고 정보를 제공하며 개인의 자산, 투자 목적, 손실 감내 수준을 반영한 개별 상담이나 맞춤형 종목 추천을 하지 않습니다.

### Q7. 머니게이트가 제 자금을 대신 운용해 주나요?

제공하지 않습니다. 고객 자금을 받거나 대신 주문을 실행하는 투자일임 서비스를 운영하지 않습니다. 개인 계좌 입금이나 자금 운용을 요구하는 연락을 받으면 공식 문의처로 진위를 확인해야 합니다.

### Q8. 제공되는 정보로 수익이 보장되나요?

보장되지 않습니다. 주식과 금융투자상품에는 원금 손실 위험이 있으며 과거 데이터, 뉴스, 요약, 시그널 또는 다른 이용자의 의견이 미래 결과를 보장하지 않습니다. 최종 판단과 책임은 이용자에게 있습니다.

### Q9. 정보가 틀리거나 늦을 수도 있나요?

그럴 수 있습니다. 외부 정보 제공처, 거래소, 네트워크, 원문 변경 등의 영향으로 데이터가 지연·누락되거나 연결 오류가 발생할 수 있습니다. 중요한 투자 판단 전에는 증권사 시세와 공식 공시, 뉴스 원문을 함께 확인해야 합니다.

### Q10. 잘못된 정보를 발견하면 어떻게 하나요?

문의 페이지의 오류 신고 채널로 종목명, 화면, 발생 시각과 확인한 내용을 보내주세요. 원문과 데이터 기준시각을 비교해 오류 여부를 확인하고, 수정이 필요한 경우 해당 정보와 관련 공지에 반영합니다.

## E-3. 머니로드

### Q11. 머니로드는 어떤 서비스인가요?

머니로드는 관심 종목의 시세·차트, 뉴스와 머니로드 요약, 가격 알림, 매수·매도·관망 시그널, 종목별 토론을 한곳에서 확인하도록 구성한 투자 보조 앱입니다.

### Q12. 관심 종목을 등록하면 무엇이 달라지나요?

관심 종목의 가격과 관련 뉴스, 시그널을 중심으로 확인할 수 있습니다. 로그인한 사용자는 관심 종목을 직접 추가하거나 해제할 수 있으며 관심 종목 등록 자체가 매수 주문이나 투자 의사 표시를 의미하지 않습니다.

### Q13. 머니로드 요약은 무엇인가요?

뉴스나 시장 이슈의 핵심을 빠르게 살펴볼 수 있도록 정리한 요약입니다. 원문의 모든 맥락을 포함하지 않을 수 있으므로 중요한 판단 전에는 기사 제목, 출처, 게시 시각과 원문을 함께 확인해야 합니다.

### Q14. 매수·매도·관망 시그널은 종목 추천인가요?

시그널은 데이터와 정해진 기준으로 포착한 변화를 매수·매도·관망 형태로 분류한 참고 정보입니다. 자동 주문이나 수익 보장이 아니며 시그널의 근거와 시장 상황을 함께 확인해야 합니다.

### Q15. 시그널이 표시되면 바로 매매해야 하나요?

아닙니다. 같은 시그널도 투자 기간, 보유 가격, 시장 상황과 위험 감내 수준에 따라 의미가 달라질 수 있습니다. 시그널 하나만으로 매매하지 말고 다양한 정보와 본인의 판단을 함께 고려해야 합니다.

### Q16. 가격 알림은 어떻게 동작하나요?

사용자가 종목과 목표 가격 조건을 설정하면 해당 가격에 도달했을 때 다시 확인할 수 있도록 알림을 제공합니다. 알림은 주문을 실행하지 않으며 시장 데이터, 네트워크, 기기 알림 설정에 따라 늦거나 누락될 수 있습니다.

### Q17. 가격 알림이 오지 않으면 어떻게 확인하나요?

기기의 알림 권한, 앱의 가격 알림 설정, 해당 알림의 활성 상태를 확인하세요. 장 운영 시간과 데이터 상태도 영향을 줄 수 있습니다. 계속 문제가 발생하면 종목과 목표 가격, 발생 시각을 문의처로 보내주세요.

### Q18. 뉴스 원문은 어디에서 볼 수 있나요?

뉴스 카드에서 기사 출처와 원문 링크를 확인할 수 있습니다. 외부 언론사 페이지의 내용·광고·접근 조건은 해당 언론사의 정책이 적용됩니다.

## E-4. 토론·커뮤니티

### Q19. 종목 토론 내용은 머니게이트의 공식 의견인가요?

아닙니다. 토론방 게시물은 각 작성자의 개인 의견이며 머니게이트의 공식 분석이나 매매 권유가 아닙니다. 게시물의 정확성과 신뢰도를 이용자가 별도로 판단해야 합니다.

### Q20. 부적절한 게시물은 어떻게 처리하나요?

운영정책에 따라 욕설, 혐오·차별, 스팸, 음란물, 불법정보, 개인정보 노출 등은 신고·검토 후 가림 또는 삭제될 수 있습니다. 관리 조치의 상세 기준은 토론 운영정책에서 확인할 수 있습니다.

### Q21. 토론방에서 본 정보를 믿고 투자해도 되나요?

토론은 시장 참여자의 분위기와 다양한 관점을 참고하는 공간입니다. 확인되지 않은 주장이나 과장된 수익 인증이 포함될 수 있으므로 공식 공시, 뉴스 원문과 다른 자료를 통해 반드시 교차 확인해야 합니다.

## E-5. 이용·문의·개인정보

### Q22. 회사 소개 사이트를 보려면 회원가입해야 하나요?

아닙니다. 머니게이트 회사 소개, 사업·서비스 안내, 공지·공시, FAQ와 문의 정보는 로그인 없이 확인할 수 있습니다. 머니로드 앱의 개인화 기능은 로그인이 필요할 수 있습니다.

### Q23. 개인정보 관련 문의는 어디로 하나요?

문의 페이지의 개인정보 문의 채널 또는 개인정보 처리방침에 표시된 담당 연락처를 이용합니다. 주민등록번호, 비밀번호, 인증번호 등 민감한 정보는 일반 문의에 입력하지 마세요.

### Q24. 머니게이트나 임직원을 사칭한 연락을 받았습니다.

금전 송금, 개인 계좌 입금, 원격제어 앱 설치, 비밀번호나 인증번호 전달을 요구한다면 응하지 마세요. 사이트에 표시된 공식 연락처로 진위를 확인하고 피해가 의심되면 관련 금융기관과 수사기관에 즉시 신고해야 합니다.
