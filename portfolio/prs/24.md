## 배경

네이버가 검색 API를 `developers.naver.com` → **NAVER Cloud Platform(NCP) API HUB**로 통합했다. 신규 발급 자격증명은 NCP API-Gateway 키라 호출 엔드포인트/헤더가 달라져, 기존 코드로는 새 키가 **인증 실패**한다. (realtime 뉴스 수집기 `news: event=collect_failed`)

## 변경

`apps/realtime/src/services/news/naver.ts`의 `fetchNaverNewsList` 요청부만 NCP 방식으로 전환:

| | 기존 | 변경 |
|---|---|---|
| 엔드포인트 | `openapi.naver.com/v1/search/news.json` | `naverapihub.apigw.ntruss.com/search/v1/news` |
| 인증 헤더 | `X-Naver-Client-Id` / `X-Naver-Client-Secret` | `X-NCP-APIGW-API-KEY-ID` / `X-NCP-APIGW-API-KEY` |
| 쿼리 | — | `format=json` 추가 |

응답 스키마(`lastBuildDate/total/start/display/items[]`, 아이템 `title/originallink/link/description/pubDate`)가 기존과 동일하여 **파싱 로직·타입·env 변수명(`NAVER_CLIENT_ID/SECRET`) 변경 없음**.

## 검증

- NCP 엔드포인트 직접 호출 → HTTP 200, 응답 스키마 기존과 동일 확인
- 로컬 realtime(`FEED=kis` + NAVER 키)에서 뉴스 **20건 수집**, 카테고리 분류 정상
- `tsc -b`(타입) / biome(린트) 통과
