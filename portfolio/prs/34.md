## 무엇이 바뀌나

### 1. 흐름 재구성

기존은 홈 화면 한 대 + 임의로 만든 시그널 카드가 중심이라 기능이 따로 놀았다. **관심 종목 → 목표가 알림 → 뉴스와 요약 → 토론과 시그널 → 판단**이라는 하나의 흐름으로 다시 짰다. 히어로는 휴대폰 두 대가 겹치는 구도.

### 2. 구조 분리 — 이게 핵심

`PhoneFrame`·시그널 카드·토론 카드·콘텐츠 데이터가 전부 `page.tsx` 한 파일에 있어 화면 하나 바꾸려면 그 파일을 헤집어야 했다.

```
page.tsx                    LandingPage 하나만 렌더 (4줄)
redesign/landing-page.tsx   섹션 조립                490줄
redesign/screens.tsx        휴대폰 화면 내부 콘텐츠   386줄
redesign/phone-frame.tsx    휴대폰 외형               72줄
redesign/content.ts         문구 데이터              142줄
redesign/icons.tsx          아이콘                    43줄
landing.css                 랜딩 전용 스타일        2,599줄
```

**휴대폰 외형 / 화면 비율 / 화면 내부 / 섹션 문구가 각각 독립**이라 이후에 화면을 넣고 빼기 쉽다.

### 3. 문구를 실제 구현에 맞춤

| 기존 | 문제 | 수정 |
|---|---|---|
| 시그널을 기술적·AI·이벤트·커뮤니티 종합 **0~100점**으로 설명 | 현재 구현은 **액션 기반(매수/매도/관망)** — 근거와 어긋남 | 실제 모델에 맞게 |
| 뉴스 **`AI 요약`** | 앱의 현재 명칭과 불일치 | **`머니로드 요약`** |

두 번째는 **같은 날 native 앱에서 바꾼 문구와 맞춘 것**이다(#30 §6-5 — 뉴스 파이프라인이 더 이상 요약을 생성하지 않아 "AI"가 사실과 어긋났다). 웹과 앱이 같은 말을 하게 됐다.

### 4. 지킨 것

- 수익 보장·보유자 인증·앱 내 주문처럼 오해를 부를 표현 **사용 안 함** — 실제 구현된 기능만 홍보
- 기존 **스토어 다운로드 링크**와 **투자 유의 안내** 유지

feat(web): 랜딩 페이지 재디자인 — 관심종목→알림→뉴스→토론 흐름으로 재구성

기존 랜딩은 홈 화면 한 대와 임의로 만든 시그널 카드가 중심이라 관심 종목,
가격 알림, 뉴스, 토론이 하나의 흐름으로 이어지지 않았다. 방문자가 앱이
실제로 제공하는 투자 흐름을 이해하기 어려웠다.

구조도 문제였다. PhoneFrame, 시그널 카드, 토론 카드, 콘텐츠 데이터가 전부
page.tsx 한 파일에 있어 화면을 교체하거나 재배치하기 어려웠다. 이번에
휴대폰 외형·화면 비율·화면 내부 콘텐츠·섹션 문구를 각각 분리해 이후에
넣고 빼기 쉽게 했다.

  page.tsx                  → LandingPage 하나만 렌더하는 얇은 라우트(4줄)
  redesign/landing-page.tsx → 섹션 조립
  redesign/screens.tsx      → 휴대폰 화면 내부 콘텐츠
  redesign/phone-frame.tsx  → 휴대폰 외형
  redesign/content.ts       → 문구 데이터
  redesign/icons.tsx        → 아이콘
  landing.css               → 랜딩 전용 스타일

문구도 실제 구현에 맞췄다. 시그널 설명이 기술적·AI·이벤트·커뮤니티를 모두
종합한 0~100점처럼 읽혔는데 현재 구현은 액션 기반(매수/매도/관망)이라
근거와 어긋났다. 뉴스 쪽 "AI 요약"도 앱의 현재 명칭인 "머니로드 요약"으로
통일했다 — 같은 날 native 앱에서 바꾼 문구와 맞춘 것이다.

수익 보장·보유자 인증·앱 내 주문처럼 오해를 부를 표현은 쓰지 않았고,
기존 스토어 다운로드 링크와 투자 유의 안내는 그대로 유지했다.

설계·구현은 별도 세션에서 진행했고, 이 커밋은 브랜치 정리와 검증만 했다.
